# Architecture Decision Records

Architecture Decision Records (ADRs) explain important choices and their tradeoffs.

## Status values

- Proposed
- Accepted
- Superseded
- Rejected

## Naming

```text
NNNN-short-description.md
```

## Template

```markdown
# ADR-NNNN: Title

- Status: Proposed
- Date: YYYY-MM-DD

## Context

What problem requires a decision?

## Decision

What are we choosing?

## Consequences

What becomes easier/harder?

## Alternatives considered

What credible options were rejected and why?
```
